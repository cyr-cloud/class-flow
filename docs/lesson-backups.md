# 수업 자동 백업과 결과 이미지

- 강사 화면이 열려 있으면 처음 접속할 때와 5분 간격으로 변경된 수업 상태를 백업한다. 탭으로 돌아와도 확인한다.
- 서버도 수업 변경 요청을 처리할 때 마지막 백업으로부터 5분이 지났다면 변경 전 상태를 보관한다.
- 샘플 열기, 자료 교체, 교안 교체, 응답 초기화, 문항/제출물 삭제, 가이드 수정 전에는 별도로 백업한다. 백업 저장 실패 시 변경을 진행하지 않는다.
- 같은 revision은 중복 보관하지 않는다. 백업에 자동 만료나 자동 삭제를 설정하지 않는다. 사용량에 따라 Redis 저장 용량 관리가 필요하다.
- 강사 화면의 ‘백업 기록 보기’에서 시각·응답 수를 확인하고 JSON을 내려받는다. 현재 화면으로 되돌리는 복원 UI는 아직 없다.
- 백업은 교안 구성, 자료 URL, 응답, 제출물 정보를 저장한다. 원본 PPT/PDF/첨부 이미지 바이트를 별도로 복제하지 않으므로 원본 파일도 유지해야 한다.
- 백업 조회는 해당 수업의 강사 권한이 필요하다. 내려받는 파일에는 강사 인증키가 포함되지 않는다.
- 수업 화면이 닫혀 있고 변경도 없으면 타이머는 실행되지 않는다. 이미 저장된 수업/백업은 유지된다.
- 설문/워드클라우드의 ‘이미지 저장’은 누른 시점의 결과를 PNG로 만든다. 긴 서술형 응답은 여러 PNG가 들어 있는 ZIP으로 내려받는다.

검증: `node scripts/test-backups.mjs` (로컬 3311, 로컬 저장소 전용), `node --test tests/renderSurveyPdf.test.mjs tests/survey.test.mjs`.
