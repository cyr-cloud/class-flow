# ClassFlow 개발 체크리스트

업데이트: 2026-09-23. 요구사항 원문은 [기능 명세서](functional-spec.md).

`[x]`는 적힌 작업 자체가 확인되었다는 뜻이다. 코드 구현, 로컬 검증, 배포 검증을 분리한다. 미체크는 미완료 또는 이번 작업에서 확인하지 않은 항목이다.

## 현재 작업 — 페이지 삽입 (로컬 전용)

- [x] 강사 페이지 **왼쪽/오른쪽** 원형 + 버튼과 종류 선택 UI 구현
- [x] 이미지 첨부·워드클라우드 페이지 데이터 구조 구현
- [x] 학생 워드클라우드 입력·실시간 집계 구현
- [x] 원본 PDF 번호와 표시 순서 분리, 기존 문항·제출물 위치 이동 구현
- [x] 운영 Redis를 사용하지 않는 로컬 전용 실행 옵션 추가
- [x] API 검증: 강사 권한, 앞/뒤 삽입, 페이지 연결 보존, 학생 응답·변경·검증
- [x] 화면 검증: 강사 추가 → 학생 참여 → 강사 집계, 이미지 표시
- [x] 화면 검증: 학생 새로고침 후 페이지 유지, 강사 전체화면 워드클라우드
- [ ] 별도 모바일 크기의 화면 검사
- [x] 추가 페이지를 포함한 PDF 생성·다운로드 버튼 구현
- [x] PDF 병합 자동 검사: 순서·쪽수·원본 페이지 크기, 잘못된 참조 차단
- [x] 샘플 61쪽 + 워드클라우드 1쪽 + 이미지 1쪽 = 63쪽 PDF 생성 UI 확인
- [ ] 생성 PDF 시각 검사 — 브라우저 도구가 blob PDF 열기를 보안 정책으로 차단하여 미완료
- [x] 타입·변경 파일 린트·diff 공백 검사 통과
- [ ] 배포 검증 — **이번에는 하지 않음: 사용자 지시로 로컬만 작업**

로컬 실행 (PowerShell):

```powershell
$env:CLASSFLOW_LOCAL_ONLY='1'
npx next dev --hostname 127.0.0.1 --port 3311
```

이 옵션은 세션·이미지·업로드 PDF·추출 노트를 `.classflow/`에 저장한다. 운영 Redis와 Blob을 사용하지 않는다. PPTX 변환에는 로컬 LibreOffice가 필요하다.

검증 명령:

```powershell
node scripts/test-insert-slides.mjs
node --test tests/mergeLessonPdf.test.mjs
npx tsc --noEmit
```

`test-insert-slides.mjs`는 127.0.0.1:3311을 대상으로 한다. 반드시 위 로컬 전용 옵션으로 서버를 실행한다. 삽입한 페이지의 삭제·순서 변경과 Lightsail 연결은 아직 구현하지 않았다.

- [x] 강사 화면에서 PPTX·PDF 파일 선택, 변환 진행·오류 안내
- [x] LibreOffice의 독립 프로필로 PPTX → PDF 변환
- [x] PDF와 발표자 노트를 로컬 서버에 저장, 학생에게 PDF 제공
- [x] 노트 조회·변환·업로드에 강사 권한 검사
- [x] PDF와 덱을 한 번에 교체하여 자료 혼합 방지
- [x] 일반 업로드에서 AI를 자동 호출하지 않도록 분리
- [x] 실제 약 36MB PPTX → 41쪽 PDF, 41쪽 노트 추출 검증
- [x] 학생 PDF 조회 성공·노트 조회 거부, 변환본 한글 화면 확인
- [x] 기존 페이지 삽입·PDF 병합 회귀 검사
- [ ] 별도 물리 기기에서 접속 검사
- [ ] 운영 배포 — 로컬 전용 단계

검증: `node scripts/test-local-ppt.mjs` (로컬 전용 서버 필요). PPTX는 최대 200MB, 결과 PDF는 60MB로 제한한다. 동시 변환 요청은 대기열에 넣지 않고 재시도 안내(429)를 반환한다. 구형 `.ppt`는 지원하지 않는다.

## AWS 준비 현황 (2026-09-23)

- [x] 사용자 승인 후 서울 Ubuntu 24.04 LTS, 4GB/2vCPU/80GB, 월 $24 classflow-server 생성, Running 확인
- [x] 계정 전체 월 $24 예산 알림 생성: 실제 $20.40 초과, 실제 $24 초과, 예상 $24 초과. 수신 주소 저장 확인. 자동 차단 아님.

- [x] Lightsail 내부 전용 변환 서비스 설치, systemd active 및 127.0.0.1:8090 바인딩 확인

기본요금 외 비용 상한을 보장하지 않는다. Vercel·Blob·Claude 비용은 이 AWS 예산에 포함되지 않는다.

- [x] 로컬 실제 PPTX 36,731,672 bytes 변환 → PDF 41쪽 저장 → 학생 PDF 바이트 일치
- [x] 발표자 노트 41쪽 보존, 원본 PPTX 다운로드 바이트 일치, 학생의 대본/원본 요청 403
- [x] 업로드 직후 대본이 빈 배열이 되는 캐시 문제 재현·수정: 자료 GET은 최신 저장소를 읽음
- [x] 로컬 학생 브라우저에서 변환 PDF 첫 장의 한글/이미지 렌더링과 1/41쪽 표시 확인
- [ ] Vercel Blob → Lightsail 작업 전달 → 결과 Blob 저장 → 배포 학생 화면 전체 흐름 (아직 연결 코드 없음)
- [x] 위 연결 코드 구현: 원본 AES-GCM 암호화, Blob 직접 업로드, CAS 대기열, outbound agent, 완료 PDF 적용 및 결과 재확인
- [x] 대기열/권한 경계/암호화 5개 검사와 기존 PDF·참여·저장소 10개 검사 통과, TypeScript·ESLint·프로덕션 빌드 통과
- [x] 배포 파일 추적에서 .classflow·.env·output 로컬 파일 0개 포함 확인

배포 홈은 PDF 업로드만 제공하는 것을 확인했다. 로컬 성공과 Lightsail 내부 성공을 운영 연결 성공으로 간주하지 않는다. 서버 PDF 전체 페이지 시각 검수·동시 부하·타임아웃 강제 재현은 이번 검증 범위 밖이다.
