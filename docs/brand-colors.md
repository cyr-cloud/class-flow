# 유니크코딩 브랜드 컬러

2026-09-26 확인. 출처: 형제 프로젝트 `youtube/channel-plan.md` 17행에 기록된 노션 ‘브랜드색상’ 팔레트. 노션 원본을 이번 작업에서 직접 조회한 것은 아니다.

색상 정의의 구현 기준은 `app/globals.css`다. `*-deep`, `*-tint`, 잉크·종이·보조 글자색은 가독성을 위한 UI 파생색이며 브랜드 원본과 구분한다.

큰 면은 흰색·크림·가드니아로 유지한다. 채팅 전체를 진한 브라운으로 채우지 않고, 기능별 버튼·요약 배지·고정 영역에 색을 나눠 쓴다. 작은 본문에는 밝은 브랜드 원색 대신 진한 파생색을 쓴다. 같은 상태는 색과 함께 텍스트·테두리·ARIA 상태로 전달한다.

버튼에는 hover, active, focus-visible, disabled 피드백을 공통 적용한다. 채팅처럼 열린 상태가 유지되는 토글은 aria-expanded로 선택 상태를 표시한다. 이동·확대 애니메이션 대신 면과 테두리 변화로 피드백을 주며, 터치에서 hover에 의존하지 않는다.

참고: [Atlassian 색상 역할·상태](https://atlassian.design/foundations/color), [Google Material 버튼 상태](https://m2.material.io/develop/web/components/buttons/).
