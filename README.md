# ClassFlow

강의용 실시간 슬라이드 + 실습 결과물 게시판.

강사가 슬라이드를 넘기면 학생 화면도 같이 넘어가고, 퀴즈 슬라이드에서는 학생이 그 자리에서
번호를 눌러 답합니다. 실습 슬라이드에는 그 실습의 게시판으로 가는 버튼이 붙습니다.

**교안을 앱용으로 다시 만들 필요가 없습니다.** 평소 쓰던 교안(`slide-content.md`) 형식을
그대로 읽어서 실습·퀴즈·정답을 알아냅니다.

---

## 1. 실행하기

```bash
npm install
npm run dev
```

브라우저에서 **http://localhost:3000** 을 엽니다. (포트를 바꾸려면 `npm run dev -- -p 3311`)

화면 맨 위에 **고정 탭**이 있습니다 — `강의 진행` / `학생 화면` / `결과물 게시판`.
마지막으로 연 세션 코드를 기억하므로, 게시판에 갔다가 `강의 진행`을 누르면 하던 수업으로 돌아옵니다.

---

## 2. 수업 전에 준비할 것 두 개

### ① 슬라이드 — PPT 그대로 올려도 됩니다

`슬라이드 올리기` 버튼에 **.pptx / .ppt / .pdf** 를 그대로 넣으면 됩니다.
PPT를 넣으면 앱이 **알아서 PDF로 바꿔서** 씁니다 (36MB 기준 20~30초).

> 변환은 이 컴퓨터에 깔린 **LibreOffice**가 합니다. 없으면 안내가 뜨는데, 그때는
> PPT에서 **다른 이름으로 저장 → PDF** 로 직접 바꿔서 올리시면 됩니다.
> 설치 경로가 특이하면 `SOFFICE_PATH` 환경변수로 지정할 수 있습니다.

**샘플**: `샘플` 버튼은 `public/samples/` 에 넣어둔 강의자료를 바로 불러옵니다.
지금은 **유코의 아지트 2회**가 들어 있습니다. `샘플`을 누르면 PDF 41쪽과 원본
마크다운의 참여요소 41문항을 함께 준비합니다. 마지막 감사 페이지에는 문항이 없습니다.
교안은 `data/samples/yuko-agit-02.md`에 두고 서버에서 읽습니다.
`퀴즈·참여 문항 바로가기`에서 13쪽(퀴즈 1), 26쪽(퀴즈 2) 등으로 바로 이동할 수 있습니다.

### ② 교안 마크다운 (선택, 하지만 이게 핵심)

`slide-content.md` 파일입니다. 이걸 같이 올리면 **퀴즈 문항·선택지·정답이 자동으로 들어옵니다.**

> ⚠️ 이 파일에는 **정답과 강사 메모**가 들어 있습니다. 학생에게 주거나 `public/` 폴더에 두지 마세요.
> 교안을 고르면 문항·선택지·정답만 현재 ClassFlow 서버에 저장합니다. 강의 대본은 보내지 않습니다.
> 학생에게는 현재 슬라이드의 정답을 공개했을 때만 해당 정답을 전달합니다.

교안 없이 PDF만 올려도 **제목으로 실습·퀴즈 슬라이드는 찾아냅니다.** 다만 슬라이드 본문이
이미지인 덱이 많아서, 문항과 정답은 교안에서만 나옵니다.

## 3. 강사: 수업 진행하기

**상단 `강의 진행` 탭** → 세션이 하나 열립니다. 주소 끝의 여섯 글자가 **세션 코드**입니다.

| 순서 | 할 일 |
|---|---|
| 1 | `슬라이드 올리기` — **PPT 또는 PDF** 선택 (PPT는 자동 변환) |
| 2 | `교안 불러오기` — `slide-content.md` 선택 |
| 3 | 아래 **강의 구성**에서 `실습 게시판 만들기` 클릭 — 실습 개수만큼 게시판이 한 번에 생깁니다 |
| 4 | 화면 아래 **학생 입장 링크**를 복사해서 학생들에게 전달 |

### 슬라이드 넘기기

- `← 이전` / `다음 →` 버튼, 또는 **키보드 ← → 키**
- 넘기면 학생 화면이 따라옵니다
- **강의 구성** 목록에서 실습 이름을 클릭하면 그 슬라이드로 바로 점프합니다

### 퀴즈 슬라이드에서

학생이 번호를 누르면 **번호별 응답 수와 막대가 실시간으로** 채워집니다.

- `정답 공개` 버튼 — 누르면 정답에 초록 배지가 붙습니다. 다시 누르면 숨깁니다
- 슬라이드를 넘기면 정답 표시는 자동으로 닫힙니다
- `응답 지우기` — 그 문항의 응답을 비웁니다 (다시 풀어보게 할 때)
- 복수 정답 문항은 여러 선택지를 누를 수 있습니다. 정답 공개 중에는 응답이 마감됩니다.

### 실습 슬라이드에서

`결과물 올리러 가기 →` 버튼이 나타납니다. 강사·학생 모두에게 보입니다.

### 전체화면 발표

`전체화면 발표` 버튼을 누르면 슬라이드가 화면을 꽉 채웁니다.

- **← → 키 또는 Space** 로 넘깁니다. **ESC** 로 나옵니다
- 참여요소가 있는 슬라이드에서는 옆에 **참여 패널**이 같이 뜹니다 — 발표하면서 응답 수를 봅니다
  (`참여 패널 접기` 로 숨길 수 있습니다)
- 학생도 `전체화면` 버튼이 있고, 전체화면 상태에서 그대로 답을 누를 수 있습니다

### 판서 (슬라이드 위에 그리기)

슬라이드 아래쪽 **`판서`** 버튼을 누르면 도구 모음이 열립니다. 일반 화면·전체화면 모두 됩니다.

| 도구 | |
|---|---|
| ✎ 펜 · ▬ 형광펜 | 자유롭게 긋기 (형광펜은 반투명) |
| ╱ 직선 · ↗ 화살표 | 끌어서 그립니다 |
| ▭ 사각형 · ◯ 원 | 끌어서 그립니다 |
| 색 6가지 | 밝은 덱·어두운 덱 양쪽에서 보이는 색으로 골랐습니다 |
| 굵기 | 가늘게 / 보통 / 굵게 |
| ↶ 되돌리기 · 지우기 | 마지막 획 취소 / 이 슬라이드 판서 전부 지우기 |

- **그린 것은 학생 화면에도 그대로 나타납니다** (그리는 동안 실시간으로)
- 판서는 **슬라이드마다 따로** 남습니다. 넘겼다가 돌아오면 그대로 있습니다
- 판서를 끄면 아래 화면을 다시 클릭할 수 있습니다

## 4. 학생: 참여하기

강사님이 준 **학생 입장 링크**를 열거나, 첫 화면에서 **세션 코드**를 넣으면 끝입니다.
가입도 로그인도 없습니다.

- 화면은 강사님을 따라 자동으로 넘어갑니다
- 퀴즈가 나오면 **번호를 누르면 됩니다.** 다시 누르면 답을 바꿀 수 있습니다
- 실습 슬라이드에서 `결과물 올리러 가기` → 게시판으로 이동

**들어간 세션의 것만 보입니다.** 헤더의 `결과물 게시판` 탭은 그 세션에 연결된 수업으로만
가고, 다른 수업 목록은 거치지 않습니다. 없는 코드를 넣으면 "이 코드로 열린 수업을 찾지
못했어요" 라고 알려줍니다.

> 다만 이건 **동선상 분리**이지 잠금장치가 아닙니다. 주소를 직접 치면 다른 게시판에 갈 수
> 있습니다. 진짜 접근 제어는 서버(Supabase)가 붙어야 됩니다. 지금은 데이터가 각 브라우저
> 안에만 있어서, 학생 기기에는 그 수업 말고는 애초에 아무것도 없습니다.

## 5. 결과물 게시판

**상단 `결과물 게시판` 탭.** 슬라이드 없이 게시판만 따로 써도 됩니다.

```
수업 (코드 6자리)
 └─ 실습 게시판 (수업 하나에 20개쯤)
     └─ 결과물 (학생이 올린 것)
```

### 강사

- `수업 만들기` → 수업 이름 입력
- 실습 게시판은 `+ 실습 추가` 하나씩, 또는 `20 개 한 번에 만들기`
- 게시판 이름·설명은 **제목을 클릭해서** 바로 고칩니다
- `링크 복사` 로 학생에게 수업 주소 전달

### 학생

`결과물 올리기` 버튼:

| 칸 | 설명 |
|---|---|
| 이름 | **비우면 익명**으로 올라갑니다. 한 번 쓰면 다음 실습에서 자동으로 채워집니다 |
| 제목 | 필수 |
| 이미지 | 클릭해서 선택 · **드래그앤드롭** · **Ctrl+V 붙여넣기**(스크린샷 바로 가능) |
| 링크 | 선택. `github.com/...` 처럼 써도 열립니다 |
| 설명 | 선택 |

### 보기 방식

**리스트 / 갤러리** 를 토글합니다. 고른 방식은 게시판마다 따로 기억됩니다.
정렬(최신순·오래된순·이름순)과 검색도 있습니다.

올린 사람만 **수정·삭제** 버튼이 보입니다 (같은 브라우저 기준).

## 6. 교안을 이렇게 쓰면 자동으로 인식됩니다

평소 쓰던 형식 그대로입니다. 참고용으로 정리해 둡니다.

| 교안에 이렇게 쓰면 | 앱이 이렇게 씁니다 |
|---|---|
| `## 슬라이드 13: 퀴즈 1 — …` | 13번 슬라이드, 제목, 퀴즈로 인식 |
| `## 슬라이드 20: [실습 1] 짧게 쓰고…` | **실습 1** 로 인식 → 게시판 연결 |
| `**[학생 참여 요소]**` 의 `Q. …` | 문항 |
| `① Chat ② Cowork ③ Design ④ Code` | 선택지 |
| `보기: ① … ② …` (슬라이드 텍스트) | 선택지 (참여요소에 없을 때) |
| 줄마다 `① 엑셀 파일 만들기` | 선택지 (위 둘 다 없을 때) |

정답 줄은 네 가지를 알아봅니다:

| 정답 줄 | 뜻 |
|---|---|
| `정답: ② Cowork` | 정답 하나 |
| `정답: ① 엑셀, ③ PPT (②는 Pro 이상)` | **정답 여럿** — 괄호 뒤 해설은 무시합니다 |
| `정답: 자유 — 채팅으로` | 정답 없는 **설문** |
| `정답: 1번 ③ / 2번 ② / 3번 ①` | 한 슬라이드에 **문항 3개**, 보기는 공유 |

**실제 교안으로 확인한 결과**: 40장짜리 교안에서 실습 7개 · 참여요소 41문항을 그대로 읽어옵니다.

## 7. 지금 되는 것과 안 되는 것

### 되는 것

- 한 컴퓨터에서 **탭 여러 개**를 열면 실시간으로 같이 움직입니다 (강사 탭 + 학생 탭들)
- 새로고침해도, 브라우저를 껐다 켜도 데이터가 남습니다
- 이미지는 긴 변 1600px / webp로 줄여 저장하므로 사진을 많이 올려도 버팁니다

### ⚠️ 아직 안 되는 것

**샘플의 슬라이드·퀴즈는 각자 노트북·휴대폰에서 참여할 수 있습니다.**

강사가 샘플을 불러온 뒤, 같은 서버의 `/student/세션코드` 주소를 공유합니다.
같은 네트워크에서는 `http://강사컴퓨터IP:3000`으로 접속합니다. 다른 기기의
`localhost`는 학생 자신의 컴퓨터를 뜻합니다. 외부 온라인 수업에는 접근 가능한 서버 배포가 필요합니다.

슬라이드 위치·문항·응답은 약 0.7초 간격으로 서버와 동기화하며 `.classflow/sessions/`에 저장합니다.
서버를 재시작해도 남습니다. 현재 저장 방식은 단일 Node 서버용이며, 여러 서버 인스턴스에는
공유 DB가 필요합니다. 강사 조작 권한은 수업을 처음 연 브라우저에 보관합니다.

직접 올린 PDF 파일, 판서, 결과물 게시판은 아직 브라우저 로컬 저장입니다.
기존 로컬 세션을 쓰려면 샘플 또는 자료를 다시 불러와 서버 수업을 준비해 주세요.

## 8. 막힐 때

| 증상 | 확인할 것 |
|---|---|
| **퀴즈 슬라이드인데 선택지가 안 뜸** | **교안(.md)을 안 올린 경우입니다.** PDF에는 문항이 안 들어 있어서, `교안 불러오기`로 교안을 올려야 문항·정답이 채워집니다. 강사 화면에 그 안내가 뜹니다 |
| 교안을 올렸는데 "참여요소 0문항" | 교안에 `## 슬라이드 N: 제목` 형식이 맞는지. `[학생 참여 요소]` 블록이 있는지 |
| 실습 게시판 버튼이 "게시판이 아직 연결되지 않았어요" | 강의 구성에서 `실습 게시판 만들기` 를 눌렀는지 |
| 다른 기기에서 안 보임 | 같은 서버 주소인지 확인하세요. 샘플은 기기 간 공유되며 직접 올린 PDF·게시판·판서는 아직 로컬입니다 |
| 학생 화면이 안 따라옴 | 세션 코드와 서버 주소, 화면의 연결 상태를 확인하세요 |
| 응답 수가 1명으로만 셈 | 탭 하나가 학생 한 명입니다. 같은 탭에서 여러 번 눌러도 1명입니다 |
| 전체화면이 안 켜짐 | 브라우저가 막은 경우입니다. 그래도 화면을 꽉 채운 발표 모드는 그대로 동작합니다 |
| 판서가 안 그려짐 | `판서` 버튼이 켜져 있는지 (켜지면 "판서 중"으로 바뀝니다) |
| PPT 변환이 안 됨 | LibreOffice가 깔려 있는지. 안 되면 PPT를 PDF로 저장해서 올리면 됩니다 |
| 샘플이 엉뚱한 파일 | `public/samples/` 안을 보세요. 거기 있는 파일을 불러옵니다 |

## 9. 개발자용

```bash
npm run dev        # 개발 서버
npm run build      # 프로덕션 빌드
npx tsc --noEmit   # 타입 검사
npx eslint app components lib   # 린트
node scripts/test-live.mjs      # 실행 중인 서버에서 동시 응답·정답 보호·복수 선택 검증
```

| 폴더 | 역할 |
|---|---|
| `app/` | 라우트 (`/`, `/teacher/[sessionId]`, `/student/[sessionId]`, `/board/...`) |
| `app/api/convert/` | PPT → PDF 변환 (로컬 LibreOffice 호출) |
| `public/samples/` | `샘플` 버튼이 불러오는 강의자료 |
| `components/` | 화면 (`TeacherView`, `StudentView`, `board/`, `lecture/`) |
| `lib/sync/` | 슬라이드 상태 동기화 (`SyncProvider`) |
| `lib/board/` | 게시판 저장소 (`BoardStore`) |
| `lib/lecture/` | 교안 파서 · 슬라이드 구성 · 응답 (`DeckStore`) · 판서 (`inkStore`) |
| `lib/store/` | 파일 바이트 저장소 (IndexedDB) |

구조·규칙·디자인 토큰은 `CLAUDE.md`, 로드맵은 `task.md` 에 있습니다.
