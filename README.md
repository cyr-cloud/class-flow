### 교안에서 참여까지, 수업의 흐름을 한곳에.

**기존 슬라이드와 마크다운 교안을 연결해, 학생이 함께 보고 답하는 수업을 만드는 도구입니다.**

강사는 슬라이드를 넘기며 학생의 반응을 확인하고, 학생은 입장 링크로 접속해 현재 슬라이드의 퀴즈에 답합니다. 교안에 작성해 둔 문항과 선택지를 다시 입력하지 않아도 됩니다.

## 왜 만들었나요?

강의를 진행할 때는 설명 외에도 여러 작업이 이어집니다. 슬라이드를 보여주고, 퀴즈를 안내하고, 학생의 답을 확인하고, 실습 결과물을 모아야 합니다. 자료와 참여 도구가 나뉘어 있으면 강사는 수업 중에도 화면과 링크를 계속 오가게 됩니다.

ClassFlow는 **강사가 이미 준비한 교안을 수업 진행의 기준으로 삼습니다.** 슬라이드 위치에 맞춰 참여 문항과 실습 동선을 연결해, 설명에서 참여로 자연스럽게 이어지는 수업을 지향합니다.

## 수업은 이렇게 흘러갑니다

1. **준비** — 슬라이드와 교안을 불러옵니다. 교안의 슬라이드 번호, 문항, 선택지, 정답을 읽습니다.
2. **진행** — 학생에게 입장 링크를 공유합니다. 강사가 넘기는 슬라이드를 학생 화면이 따라갑니다.
3. **참여** — 해당 슬라이드의 퀴즈에 학생이 답합니다. 강사는 선택지별 응답 수와 비율을 확인합니다.
4. **확인** — 정답을 공개해 함께 확인하거나, 응답을 초기화해 다시 풀어봅니다.

실습 슬라이드에는 결과물 게시판을 연결할 수 있습니다. 게시판은 현재 브라우저 내 체험 단계이며, 다른 기기 간 결과물 공유는 후속 개발 범위입니다.

## 샘플로 체험하기

**별도의 회원가입이나 자료 준비 없이 시작할 수 있습니다.** 저장소에 ‘유코의 아지트 2회 — 프롬프팅 + Claude 활용법’ 샘플을 포함했습니다.

| 샘플 구성 | 내용 |
| --- | --- |
| 슬라이드 | PDF 41쪽 — 본문 40쪽과 마지막 감사 페이지 |
| 참여 문항 | 퀴즈·설문 등 41문항 |
| 실습 | 교안에서 인식하는 실습 7개 |
| 원본 자료 | PDF, PPTX, 마크다운 교안 포함 |

### 혼자 둘러보기

1. 첫 화면에서 **새 강의 시작 → 샘플**을 누릅니다.
2. **퀴즈·참여 문항 바로가기**에서 **13쪽**을 선택합니다.
3. 상단 **강사 / 학생** 토글을 학생으로 바꿔 답을 선택합니다.
4. 강사로 돌아와 집계 결과를 확인하고 **정답 공개**를 누릅니다.
5. **26쪽**에서는 여러 답을 고르는 복수 선택 퀴즈를 체험할 수 있습니다.

### 두 화면으로 체험하기

강사 화면 아래의 **학생 입장 링크**를 새 탭이나 다른 기기에서 엽니다. 강사가 슬라이드를 넘기고 학생이 답하면 양쪽 화면이 함께 갱신됩니다.

같은 네트워크의 다른 기기에서는 `localhost` 대신 **서버를 실행한 컴퓨터의 IP 주소**로 접속해야 합니다. 현재 공개 배포 URL은 제공하지 않으며, 아래 명령으로 로컬에서 실행할 수 있습니다.

## 현재 구현 범위

| 기능 | 현재 상태 |
| --- | --- |
| 샘플 수업 | PDF와 교안 문항을 한 번에 불러오기 |
| 첫 방문 온보딩 | 3단계 사용법 안내와 `샘플로 1분 체험하기` 바로가기 |
| 슬라이드 동기화 | 같은 서버에 접속한 강사·학생의 현재 페이지 공유 |
| 실시간 퀴즈 | 단일·복수 선택, 답 변경, 선택지별 집계, 응답 초기화 |
| 정답 공개 | 공개 전 학생 API 응답에서 정답 제외, 공개 중 답 제출 마감 |
| 강사 / 학생 토글 | 같은 세션에서 화면 전환. 강사 조작은 수업을 만든 브라우저의 권한으로 확인 |
| 전체화면 발표 | 슬라이드와 참여 패널 표시, 키보드로 페이지 이동 |
| 슬라이드 판서 | 펜·형광펜·도형, 슬라이드별 저장. 같은 브라우저 내 동기화 |
| 실습 게시판 | 이미지·링크·설명 등록, 목록·갤러리 보기. 브라우저 로컬 저장 |
| 자료 업로드 | PDF와 규격에 맞춘 마크다운 지원. 업로드한 PDF는 브라우저 로컬 저장 |
| PPT 변환 | 서버에 LibreOffice가 설치된 환경에서 PDF로 변환 |

**현재는 핵심 수업 흐름을 검증하는 프로토타입입니다.** 기기 간 체험에는 저장소에 포함된 샘플을 사용해 주세요. 직접 올린 PDF, 판서, 게시판의 데이터는 아직 기기 간 공유되지 않습니다.

## AI를 활용한 개발

ClassFlow는 실제 강의 운영의 요구사항을 바탕으로, **OpenAI Codex와 함께 기능 구현 및 검증을 진행한 프로젝트**입니다.

- 자연어로 설명한 수업 흐름을 강사·학생 화면과 상호작용으로 구현했습니다.
- 실제 마크다운 교안을 확인하며 문항 파싱과 샘플 연동을 구현했습니다.
- 동시 응답, 답 변경, 정답 공개, 복수 선택을 검증하는 API 테스트를 작성하고 실행했습니다.

현재 앱의 교안 처리는 **정해진 마크다운 형식을 읽는 규칙 기반 파서**입니다. 앱 안에서 AI 모델이 문항이나 강의 대본을 생성하는 기능은 아직 구현하지 않았습니다.

## 바로 실행하기

Node.js와 npm이 설치된 환경에서 실행합니다. 포함된 샘플은 별도 API 키나 LibreOffice 설치 없이 체험할 수 있습니다.

```bash
git clone https://github.com/cyr-cloud/class-flow.git
cd class-flow
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)에 접속한 뒤 **새 강의 시작 → 샘플**을 선택하세요.

이미 설치했다면 `npm run dev`만 실행하면 됩니다. 포트를 바꾸려면 `npm run dev -- -p 3311`을 사용합니다. 프로덕션 실행은 `npm run build` 후 `npm start`입니다. 빌드 시 Google Fonts 다운로드를 위한 네트워크 연결이 필요합니다.

### 직접 만든 교안 연결하기

`슬라이드 올리기`로 PDF를, `교안 불러오기`로 마크다운을 선택합니다. 교안은 아래 구조를 따릅니다. 마크다운의 슬라이드 번호와 PDF 페이지 번호가 일치해야 합니다.

```markdown
## 슬라이드 13: 퀴즈 1 — 어떤 기능을 사용할까요?

**[학생 참여 요소]**
Q. 폴더의 자료를 정리해 보고서를 만들려면?
① Chat ② Cowork ③ Design ④ Code
정답: ② Cowork
```

`정답: 자유`는 설문, `정답: ① …, ③ …`는 복수 정답으로 인식합니다. 제목의 `[실습 1]` 표기는 실습 게시판 연결에 사용합니다. 이미지로 된 슬라이드의 문항을 PDF만으로 추출하는 기능은 제공하지 않습니다.

## 저장과 배포

현재 서버는 슬라이드 위치·교안 구성·퀴즈 응답을 약 **0.7초 간격**으로 동기화하고, `.classflow/sessions/`에 저장합니다. 이 실행 데이터는 Git에서 제외됩니다.

- **현재 지원 환경:** 파일을 지속적으로 읽고 쓸 수 있는 단일 Node.js 서버.
- **Vercel 배포 준비:** 세션과 응답 저장을 공유 DB로 전환해야 합니다. 현재 파일 저장 방식 그대로는 Vercel Functions에서 동작하지 않습니다.
- **PPT 변환:** LibreOffice 실행 환경이 필요합니다. 설치 경로는 `SOFFICE_PATH`로 지정할 수 있으며, 샘플 PDF 사용 시에는 변환이 필요 없습니다.
- **교안 취급:** 강사 메모와 정답이 포함된 교안은 `public/`에 두지 않습니다. 샘플 마크다운은 서버용 `data/samples/`에 있으며, 저장소 자체에는 원본이 포함되어 있습니다.

## 개발 정보

| 영역 | 사용 기술 |
| --- | --- |
| 웹 애플리케이션 | Next.js 16 · React 19 · TypeScript |
| 스타일 | Tailwind CSS 4 |
| 슬라이드 렌더링 | PDF.js |
| 세션·퀴즈 동기화 | Next.js Route Handlers · HTTP 폴링 · 서버 JSON 파일 |
| 로컬 데이터 | localStorage · IndexedDB · BroadcastChannel |
| PPT 변환 | LibreOffice |

```text
app/                 페이지 및 API
components/          강사·학생 화면, 발표·퀴즈·게시판 UI
lib/lecture/         교안 파서, 문항·응답 처리, 판서
lib/live/            서버 세션 저장 및 클라이언트 동기화
lib/board/           실습 게시판 저장소
lib/sync/            슬라이드 상태·PDF 접근
lib/store/           IndexedDB 파일 저장
data/samples/        서버에서 읽는 샘플 마크다운
public/samples/      브라우저에서 읽는 샘플 PDF
scripts/             API 검증 스크립트
```

### 검증

```bash
npx tsc --noEmit
npx eslint app components lib
npm run build

# 개발 서버를 실행한 상태에서 별도 터미널로 실행

```
