# sample-pdfs

강의 테스트용 PDF를 여기에 둡니다.

## 쓰는 법
1. 이 폴더에 강의 PDF를 넣기 (PPT는 "다른 이름으로 저장 → PDF"로 변환)
2. 강사 화면(`/teacher/[세션코드]`)의 **PDF 업로드** 버튼 클릭
3. 파일 창에서 이 폴더의 PDF 선택
4. 이전/다음(또는 ← / → 키)으로 넘기면 학생 화면이 따라옵니다

> 참고: 앱은 이 폴더를 자동으로 읽지 않습니다. 업로드 버튼으로 고른 PDF는
> 브라우저의 IndexedDB에 저장되어 같은 브라우저의 학생 탭이 함께 봅니다.
> (다른 기기 간 공유는 Supabase 도입 후 — task.md의 Phase 3)
