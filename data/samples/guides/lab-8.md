## 이번 실습에서 만드는 것

- `02_output` 폴더에 합친 보고서 파일 1개 (시트 2장 이상)

필요한 정보가 한 파일에 다 있는 경우는 없습니다. 매출은 여기, 연락처는 저기,
월별 파일은 또 폴더로 따로 있습니다. 손으로 하면 파일을 번갈아 열며 옮겨 적어야 하지만,
폴더가 이미 붙어 있으니 그럴 필요가 없습니다.

이번엔 점포 두 곳이 안 맞습니다. 직접 찾아보세요.
힌트만 드리면 — 올해 인수한 점포가 하나, 연말에 문 여는 점포가 하나 있습니다.

## 이렇게 해보세요

### Step 1. 두 번째 파일을 먼저 열어보기

`01_docs/branch-info.csv` 를 엑셀로 열어 어떤 칸이 있는지 봅니다.

확인할 것 하나 — **두 파일에 공통으로 있는 칸이 무엇인가요?**

합치려면 이어붙일 기준이 있어야 합니다. 두 표에 똑같이 들어 있는 칸이 그 기준이 됩니다.
여기서는 점포 이름이 그 역할을 합니다. 기준이 없으면 아무리 시켜도 못 합니다.

### Step 2. 두 자료 합치기

```
02_output/sales-2026-clean.xlsx 와 01_docs/branch-info.csv 를
점포 이름을 기준으로 합쳐 주세요.

- 합친 표에는 점포 · 연월 · 매출액 · 담당자 · 연락처 · 점포 주소가 들어가야 합니다
- 한쪽 파일에만 있는 점포가 있으면 따로 알려주세요
- 결과는 02_output/sales-2026-report.xlsx 로 저장해 주세요

지어내지 말고 두 파일에 실제로 있는 내용만 써 주세요.
```

![합친 파일을 저장했다는 답과 한쪽에만 있는 점포 두 곳을 짚어준 표](/samples/guides/lab-8-1.png)

"한쪽에만 있는 점포가 있으면 알려주세요" 가 중요합니다.
이걸 안 넣으면 조용히 빼고 합쳐버립니다. 빠진 게 있다는 걸 모르는 게 제일 위험합니다.

### Step 3. 빠진 것이 없는지 확인하기

답에 **두 방향 다** 나왔는지 봅니다.

| 확인 | 무엇이 나와야 하나 |
|---|---|
| 매출표에만 있는 점포 | 점포 정보가 없는 곳이 하나 있습니다 |
| 점포 정보에만 있는 점포 | 매출이 없는 곳이 하나 있습니다 |

한쪽만 알려줬다면 절반만 맞은 것입니다. 이렇게 되물으세요.

```
반대쪽도 확인해 주세요.
점포 정보에는 있는데 매출 자료에는 없는 점포도 알려주세요.
```

![되물었더니 점포정보에만 있는 점포 한 곳을 찾아 담당자·연락처·주소까지 보여준 답](/samples/guides/lab-8-2.png)

새로 문을 연 점포는 매출이 아직 없을 수 있습니다. 빠진 게 아니라 원래 없는 것일 수도 있어요.
그래서 "왜 없는지"까지 확인해야 합니다.

### Step 4. 폴더 안 파일을 한 번에 처리하기

`01_docs/monthly-sales` 안에 월별로 쪼개진 파일 열두 개가 들어 있습니다.
**하나씩 열지 않습니다.** 폴더만 알려주면 됩니다.

```
01_docs/monthly-sales 폴더 안의 파일을 전부 읽어서
월별 매출 합계를 구해 주세요.

- 파일이 몇 개였는지 먼저 알려주세요
- 월별 합계를 표로 보여주세요
- 결과는 02_output/sales-2026-report.xlsx 에 "월별합계" 시트로 추가해 주세요

지어내지 말고 실제 파일 내용만 쓰세요.
```

![CSV 12개를 읽어 440행이라고 답하고 월별 합계를 표로 보여준 화면](/samples/guides/lab-8-3.png)

![엑셀에 추가된 월별합계 시트 — 열두 달 합계와 맨 아래 합계 440행이 보인다](/samples/guides/lab-8-4.png)

이게 폴더를 붙여둔 값어치입니다. 파일이 열두 개든 백 개든 폴더 이름 하나만 말하면 됩니다.
다음 달에 파일이 하나 늘어도 똑같이 시키면 되고요.

### Step 5. 회사 자료를 쓸 때의 기준 확인하기

오늘 쓴 파일은 연습용으로 만든 가짜 자료입니다. 실제 업무에 쓰실 때 지킬 것을 짚고 갑니다.

| | |
|---|---|
| 연습할 때 | 가짜 자료 · 공개된 샘플 자료만 씁니다 |
| 실무에 쓸 때 | 회사가 허락한 범위 안에서만. 확인 없이 연결하지 않습니다 |
| 특히 조심 | 이름·연락처·주민번호·계좌 같은 개인정보가 든 파일 |
| 폴더 연결 | 바탕화면이나 문서 폴더를 통째로 붙이지 않습니다. 일할 폴더만 따로 만들어 붙입니다 |

배우는 건 자료가 아니라 만드는 방법입니다. 오늘 방법을 익혀두면,
회사에서 허락받은 자료로 똑같이 하시면 됩니다.

## 이렇게 되면 성공이에요

- `02_output`에 보고서 파일 1개(시트 2장 이상)가 생겼다
- 양쪽 방향 불일치 2건을 다 확인했다
- 월별 파일 12개를 한 번에 읽어 월별 합계 시트가 추가됐다
