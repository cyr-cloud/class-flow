## 이번 실습에서 만드는 것

- Claude 예약 목록에 등록된 내 작업 1건
- 그 예약이 돌아서 내 카톡에 온 메시지 1건

여기까지 한 것을 세어보면 이렇습니다.

1. 내 폴더를 맡겼습니다
2. 파일을 던져서 정리를 받았습니다
3. 여러 파일을 한 번에 처리했습니다
4. 결과를 카톡으로 받았습니다

그런데 넷 다 내가 눌러야 돌았습니다. 이번에 하나만 더 붙입니다.

5. **내가 안 눌러도 정해진 때에 알아서 돈다.**

이 다섯 칸이 이어지면, 컴퓨터를 켜두기만 해도 정리된 결과가 알아서 카톡에 도착해 있습니다.

## 시작하기 전에 — 두 가지만 알고 갑니다

### ① 예약은 기본적으로 클라우드에서 돕니다

내 컴퓨터가 꺼져 있어도 정해진 때에 됩니다. 그런데 우리가 거는 건 다릅니다.
내 폴더의 파일을 읽어야 하니까요. 파일이 그 컴퓨터에 있어서 클라우드에서는 못 봅니다.

그래서 **「이 컴퓨터에 연결」** 을 지정해줘야 합니다. 그러면 실행 시각에 컴퓨터와 앱이 켜져 있어야 합니다.

**이건 만들 때만 지정할 수 있습니다. 나중에 못 붙입니다.**
빠뜨리고 만드셨으면 지우고 다시 만드셔야 합니다.

### ② 예약은 매번 새 대화에서 돕니다

오늘 나눈 대화를 기억하지 못합니다. "아까 그 파일" 같은 말이 안 통합니다.
그래서 프롬프트를 그것만 읽어도 알아들을 수 있게 — 어느 폴더의 무슨 파일인지 이름을 다 적어 — 써야 합니다.

### 시각은 컴퓨터가 켜져 있는 때로

| 이런 분은 | 이렇게 |
|---|---|
| 회사에서 컴퓨터를 종일 켜둔다 | 근무 중 아무 때나 (앱도 열어두세요) |
| 집 컴퓨터를 잠깐씩만 켠다 | 다음 수업 시간쯤으로 |
| 노트북을 들고 다닌다 | 켜져 있을 때를 골라 잡고, 안 오면 그것대로 확인이 됩니다 |

예약 목록 화면 오른쪽에 「절전 모드 방지」 스위치가 있습니다.
컴퓨터가 켜져 있어도 잠들어 버리면 안 돕니다. "안 왔어요"의 대부분이 이것 때문입니다.

## 이렇게 해보세요

### Step 1. 예정됨 자리 열기

1. Claude 앱 왼쪽 목록에서 **예정됨** 을 찾아 누릅니다
2. **예약된 작업** 화면이 열립니다. 오른쪽 위 **새 작업** 을 누릅니다
3. 두 가지가 나옵니다. **Claude와 함께 창작하기** 를 고르세요
   - 옆의 **수동으로 설정** 은 칸을 하나씩 직접 채우는 방식입니다. 오늘은 안 씁니다

![새 작업을 누르면 나오는 Claude와 함께 창작하기 · 수동으로 설정 두 갈래](/samples/guides/lab-10-2.png)

### Step 2. 말로 설명해서 만들기

누르면 "어떤 작업을 자동으로 돌리고 싶으세요?" 하고 물으면서 추천 목록을 띄웁니다.
그 추천은 사람마다 다르게 나오고, 우리가 만들 건 거기 없습니다.
목록 맨 아래 `기타` 를 누르거나, 화면 아래 입력칸("또는 직접 답장…")에 직접 적으시면 됩니다.

거기에 아래를 그대로 넣습니다. **대괄호 안만 본인 것으로 바꾸세요.**

```
매일 [14:00]에 도는 작업을 만들어줘. 이 컴퓨터에 연결해서 만들어줘.

- claude_lab 프로젝트의 01_docs 폴더에 있는 매출 자료를 읽어줘
- 점포별 매출을 정리해줘
- 가장 많이 팔린 점포 세 곳, 가장 적게 팔린 점포 세 곳, 전체 합계
- 정리한 내용을 카카오톡 나챗방에 보내줘
- 자료에 없는 숫자는 만들지 마
```

![추천 목록 맨 아래 기타와, 아래 입력칸에 붙여넣은 예약 프롬프트](/samples/guides/lab-10-3.png)

**만드는 중에 창이 세 번 뜹니다.**

| 뜨는 창 | 누를 것 |
|---|---|
| "이 폴더를 추가하려고 합니다" — `claude_lab` 경로가 보입니다 | 폴더 추가 |
| 카톡 도구를 쓰겠다는 창 — 시험 삼아 한 번 보내봅니다 | 이 작업에 허용 |
| "작업 예약" 확인창 — 이름·시각·`이 컴퓨터 필요` 가 보입니다 | **일정** |

![첫 번째 창 — claude_lab 경로가 보이는 폴더 추가 확인창](/samples/guides/lab-10-4.png)

![두 번째 창 — 카톡 도구를 쓰겠다는 창의 이 작업에 허용](/samples/guides/lab-10-5.png)

![세 번째 창 — 이름·시각·이 컴퓨터 필요가 적힌 작업 예약 창의 일정 단추](/samples/guides/lab-10-6.png)

마지막 「일정」을 눌러야 진짜로 등록됩니다. 여기까지 다 해놓고 이걸 안 누르면 예약이 안 생깁니다.
시험 발송이 한 번 가는데, 카톡에 `[테스트]` 로 시작하는 메시지가 오면 제대로 연결된 것입니다.

![예약이 하나 만들어진 뒤의 화면](/samples/guides/lab-10-7.png)

### Step 3. 만들어진 예약을 열어서 확인하기

목록에서 방금 만든 작업을 눌러 열어보세요. 다섯 가지만 확인합니다.

- **이름** — 목록에서 알아볼 만한 이름인가
- **프롬프트** — 카톡으로 보내라는 줄이 들어 있나
- **빈도·시각** — 내가 말한 시각으로 되어 있나
- **폴더** — `claude_lab` 프로젝트가 잡혀 있나
- **이 컴퓨터에 연결** — 카드에 `이 컴퓨터 필요` 또는 `이 컴퓨터에서만` 표시가 붙어 있나

`이 컴퓨터에서만` 표시가 안 붙어 있으면 지우고 다시 만드세요. 그것만은 나중에 못 붙입니다.
다른 칸(이름·프롬프트·시각)은 나중에 고칠 수 있습니다.

![만든 작업을 열어 이름·지침·빈도·폴더·이 컴퓨터 필요 표시를 확인하는 화면](/samples/guides/lab-10-8.png)

### Step 4. 기다리지 말고 지금 실행해 보기

작업을 열어보시면 오른쪽 위에 **▷ 지금 실행** 이 있습니다.

![작업 화면 오른쪽 위의 지금 실행 단추](/samples/guides/lab-10-9.png)

1. **지금 실행** 을 누릅니다
2. 잠깐 기다리면 작업이 한 바퀴 돕니다
3. 카톡 나와의 채팅방을 열어봅니다

이런 모양으로 옵니다.

```
[매출요약 2026-09-03]
기간 2026-01~2026-12
합계 1,067,716,000원
상위3 전주점 1.68억 군산점 1.34억 익산점 1.20억
하위3 무주점 0.43억 진안점 0.48억 임실점 0.55억
```

![예약이 돌아서 카톡 나와의 채팅방에 도착한 매출요약 메시지](/samples/guides/lab-10-10.png)

점포 이름과 숫자가 자료와 맞는지 한 번 보세요. 상위 세 곳은 큰 시내 점포,
하위 세 곳은 작은 점포가 나오는 게 맞습니다.

**안 왔으면 세 가지만 봅니다.**

| 확인 | 이렇게 |
|---|---|
| 폴더가 잡혔나 | 작업 화면에서 폴더 칸에 `claude_lab` 이 보이는지 |
| 카톡 줄이 있나 | 지침에 "카카오톡 나챗방에 보내줘" 가 들어 있는지 |
| 커넥터가 붙어 있나 | 사용자 지정 → 커넥터 → 내 것 에 PlayMCP가 있는지 |

셋 중 빠진 걸 고치고 **지금 실행**을 한 번 더 누르시면 됩니다.

### Step 5. 절전 모드 방지 켜기

이건 목록 화면에 있습니다. 개별 작업 화면에는 없습니다.

![예약된 작업 목록 안내 줄 오른쪽 끝의 절전 모드 방지 스위치](/samples/guides/lab-10-11.png)

1. 왼쪽 목록에서 **예정됨** 을 다시 눌러 **예약된 작업** 목록으로 돌아옵니다
2. 위쪽에 "컴퓨터에서 실행하도록 설정된 작업은…" 이라는 안내 줄이 있습니다
3. 그 줄 오른쪽 끝에 **절전 모드 방지** 스위치가 있습니다. 켜주세요

## 이렇게 되면 성공이에요

- 예약 목록에 내가 만든 작업 1건이 보인다
- 작업 카드에 `이 컴퓨터 필요` 표시가 붙어 있다
- **지금 실행**을 눌렀더니 카톡으로 요약이 왔다
- 절전 모드 방지가 켜져 있다

정한 시각이 지나면 카톡을 다시 열어보세요. 안 왔으면 컴퓨터가 켜져 있었는지(잠들어 있었는지도) 먼저 확인합니다.
매일 같은 숫자가 올 겁니다 — 원본 자료가 안 바뀌니까요. 고장 난 게 아닙니다.

## 직접 해보기 (도전)

### ① 이대로 하나 더 걸어보기 — 여기까지가 기본

방금은 점포별로 뽑았죠. 이번엔 상품군별로 뽑아봅니다. 같은 자료인데 보는 각도만 바꾸는 겁니다.

```
매일 [09:00]에 도는 작업을 하나 더 만들어줘. 이 컴퓨터에 연결해서 만들어줘.
기존 14시 작업은 그대로 두고, 새 작업으로 추가해줘.

- claude_lab 프로젝트의 01_docs 폴더에 있는 매출 자료 전체를 읽어줘
- [상품군]별로 매출을 정리해줘
- [생활용품·식품·의류] 각각의 합계와, 전체에서 몇 퍼센트인지 알려줘
- 그 셋 말고 다른 상품군이 있으면 "기타"로 묶어서 같이 세줘
- 정리한 내용을 카카오톡 나챗방에 보내줘. 200자를 넘기지 마
- 파일은 따로 안 만들어도 돼
- 자료에 없는 숫자는 만들지 마
```

만들고 나서 **지금 실행**을 눌러보세요. 이런 게 옵니다.

```
[상품군 요약]
생활용품 4.4억 (42%)
식품 4.0억 (38%)
의류 2.1억 (20%)
합계 10.6억
```

![상품군별 합계와 비중이 정리되어 카톡으로 온 두 번째 예약 결과](/samples/guides/lab-10-12.png)

퍼센트를 다 더하면 100이 나와야 합니다. 안 나오면 다시 시키세요.

**왜 이렇게 길게 적었나** — 프롬프트가 짧으면 Claude가 하나씩 되물어봅니다.
"집계할 기간은 어디까지인가요?", "기존 14시 작업은 어떻게 할까요?",
"다른 상품군이 있으면 어떻게 할까요?", "파일도 남길까요?" 같은 것들이요.
위 프롬프트는 이 넷을 미리 다 답해둔 것입니다. 기준을 내가 정해서 주지 않으면
되묻거나, 알아서 정해버립니다. 되물으면 대개 첫 번째 선택지가 우리가 원하는 것입니다.

대괄호를 `[점포]별로` · `[연월]별로` · `[담당자]별로` 로 바꿔보셔도 됩니다.
한 줄만 바꾸면 다른 보고서가 됩니다.

### ② 내 일로 바꿔보기 — 하고 싶은 분만

본인이 실제로 반복하는 일로 옮겨봅니다. 어떤 일이 어울리는지 예시 넷입니다.

| 이런 일 | 왜 어울리나 |
|---|---|
| 매달 오는 정산·매출 파일 정리 | 폴더에 쌓이고, 매번 같은 방식으로 정리하니까 |
| 회의록에서 결정사항만 뽑기 | 여러 문서를 읽어 한 장으로 줄이는 일이라 |
| 다음 수업·행사 자료가 다 있는지 점검 | 폴더에 뭔가 빠졌는지 확인만 하면 되니까 |
| 주간 보고서 초안 만들기 | 자료는 이미 폴더에 있고, 형식이 매번 같으니까 |

넷 다 ① 폴더에 자료가 있고 ② 하는 일이 매번 같습니다. 이 둘이 아니면 예약으로 만들기 어렵습니다.

네 칸으로 쪼개봅니다.

| 칸 | 내 경우 |
|---|---|
| 무엇을 읽나 | 어느 폴더의 어떤 파일인가 |
| 무엇을 하나 | 정리·요약·계산 중 무엇인가 |
| 무엇이 나오나 | 표인가 문서인가 짧은 메시지인가 |
| 어디로 오나 | 카톡인가, 폴더에 파일로 남기는가 |

채운 걸 그대로 프롬프트로 옮깁니다. 「회의록에서 결정사항 뽑기」로 채우면 이렇게 됩니다.

```
매일 [09:00]에 도는 작업을 만들어줘. 이 컴퓨터에 연결해서 만들어줘.

- [claude_lab] 프로젝트의 [01_docs/meeting] 폴더에 있는 [회의록 파일들]을 읽어줘
- [결정된 것과 담당자만] 뽑아줘
- [다섯 줄 이내로 짧게] 정리해줘
- 정리한 내용을 카카오톡 나챗방에 보내줘
- 자료에 없는 내용은 만들지 마
```

내 자료를 쓰시려면 그 폴더가 프로젝트에 붙어 있어야 합니다. 없는 폴더를 적으면 못 찾습니다.

## 예약을 지우거나 잠시 멈추려면

- 예약 목록에서 해당 작업을 열면 **끄기·삭제**가 있습니다
- 매일 오는 게 부담되면 꺼두었다가 필요할 때 다시 켜시면 됩니다
