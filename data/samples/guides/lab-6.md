## 이번 실습에서 만드는 것

- 바탕화면에 `claude_lab` 폴더 1개 + 하위 폴더 3개
- Claude 앱에 그 폴더가 붙은 프로젝트 1개

앱은 아무 데서나 일하지 않습니다. **어느 폴더에서 일할지를 먼저 정해줘야** 합니다.
그 폴더에 이름표까지 달아둔 것을 **프로젝트**라고 부릅니다.

바탕화면이나 다운로드 폴더를 통째로 연결하면 그 안의 모든 파일이 대상이 됩니다.
새 방을 하나 만들어 거기서만 일을 시키면, 뭔가 잘못돼도 그 방 안에서 끝납니다.

## 이렇게 해보세요

### Step 1. 작업 폴더 만들기

바탕화면에 새 폴더를 만들고 이름을 `claude_lab` 으로 합니다. 그 안에 폴더 세 개를 더 만듭니다.

```
claude_lab/
├─ 01_docs/       오늘 쓸 자료를 넣는 칸
├─ 02_output/     결과물이 생기는 칸 (비워둡니다)
└─ 99_backup/     원본을 그대로 두는 칸 (비워둡니다)
```

![탐색기에서 claude_lab 안에 01_docs·02_output·99_backup 세 폴더가 만들어진 모습](/samples/guides/lab-6-1.png)

- 폴더 이름은 **영어 그대로**, 띄어쓰기 대신 밑줄(`_`)을 씁니다. 한글 폴더 이름은 프로그램에 따라 글자가 깨질 수 있습니다.
- `99_backup`은 원본을 손대지 않고 남겨두는 칸입니다. 번호를 99로 붙인 건 목록 맨 아래에 오게 하려는 것입니다.

### Step 2. 오늘 쓸 자료 넣기

안내받은 샘플 파일을 내려받아 `01_docs` 안에 넣습니다. 세 가지가 들어 있습니다.

- `sales-2026-messy.csv` — 오늘의 주인공. 점포 열두 곳의 한 해 매출을 상품군별로 적은 표(440줄)이며, 일부러 지저분하게 만들어 둔 자료입니다
- `branch-info.csv` — 점포의 담당자·연락처·주소·개점일·면적이 든 표입니다. 매출표에는 없는 정보라 뒤에서 둘을 합칩니다
- `monthly-sales` 폴더 — 같은 매출을 월별로 쪼개 놓은 파일 열두 개입니다. 압축이면 풀어서 폴더째 넣으세요

전부 연습용으로 만든 가짜 자료입니다. 실제 회사 자료가 아니고 개인정보도 들어 있지 않습니다.

### Step 3. 프로젝트 만들면서 폴더 붙이기

1. 앱 왼쪽 맨 위에서 **채팅 및 Cowork** 쪽이 눌려 있는지 확인합니다. 옆의 `</> Code` 는 다음 회차에 씁니다.
2. 그 아래 **+ 새로 생성**을 누릅니다.
3. 입력창 아래에서 **Cowork** 를 고릅니다. 화면에는 영어 `Cowork` 로 적혀 있습니다.

![입력창 아래 채팅 옆에 있는 Cowork 단추](/samples/guides/lab-6-2.png)

4. 이어서 **프로젝트** 자리를 누릅니다. 목록이 열립니다.

![입력창 아래 왼쪽 끝의 프로젝트 글자](/samples/guides/lab-6-3.png)

5. 목록 맨 아래 **+ 새 프로젝트 생성**을 누릅니다.
   - 바로 아래 「폴더 추가」는 누르지 않습니다. 폴더만 달랑 붙이는 길이라 이름표도 없고 지침도 못 답니다.

![프로젝트 목록 맨 아래의 + 새 프로젝트 생성과 그 아래 폴더 추가](/samples/guides/lab-6-4.png)

6. 창 아래쪽 **⊞ 폴더 사용**을 **먼저** 누릅니다.
   - 이름과 목표를 먼저 적으면 폴더를 연결하는 순간 적은 게 지워집니다. **폴더 → 이름 → 목표** 순으로 갑니다.

![프로젝트 생성 창 왼쪽 아래의 폴더 사용 단추와 펼쳐진 폴더 검색 목록](/samples/guides/lab-6-5.png)

7. 바탕화면 → `claude_lab` 을 찾아 선택합니다. 그 안의 `01_docs`가 아니라 `claude_lab` **자체**를 고릅니다.

![폴더 선택 창에서 claude_lab 을 연 뒤 오른쪽 아래 폴더 선택을 누르는 모습](/samples/guides/lab-6-6.png)

8. **무엇을 작업 중이신가요?** 칸에 `sales_report` 라고 적습니다.
   - 폴더를 연결하면서 이 칸이 폴더 이름으로 바뀌어 있을 수 있습니다. 지우고 다시 적으세요.
   - 폴더는 `claude_lab`, 프로젝트 이름은 `sales_report` — 서로 다른 게 맞습니다.
9. **어떤 목표를 달성하려고 하시나요?** 칸에 한 줄 적습니다. 아래를 그대로 쓰셔도 됩니다.

```
초록마트 점포별 매출 자료를 정리해서 보고서로 만드는 작업입니다.
```

10. 오른쪽 아래 **프로젝트 생성**을 누릅니다.

![이름·지침·로컬 폴더가 채워진 프로젝트 생성 창과 오른쪽 아래 프로젝트 생성 단추](/samples/guides/lab-6-8.png)

11. 권한을 묻는 창이 뜨면 **항상 허용**을 고릅니다. "한 번만 허용"을 고르면 앱을 껐다 켤 때마다 다시 물어봅니다.

![claude_lab 파일 변경을 허용할지 묻는 창의 항상 허용 단추](/samples/guides/lab-6-7.png)

### Cowork가 회색이라 안 눌릴 때 (윈도우)

계정 문제가 아니라 윈도우 기능 몇 개가 꺼져 있어서 그렇습니다.

1. 시작 단추 옆 검색창에 `windows 기능` 이라고 칩니다
2. **Windows 기능 켜기/끄기**를 누릅니다

![시작 검색창에 windows 기능을 쳤을 때 나오는 Windows 기능 켜기/끄기 항목](/samples/guides/lab-6-9.jpg)

3. 목록에서 **Windows 하이퍼바이저 플랫폼**, **가상 머신 플랫폼** 두 개를 찾아 체크합니다
4. **확인**을 누릅니다

![Windows 기능 목록에서 가상 머신 플랫폼과 Windows 하이퍼바이저 플랫폼에 체크한 모습](/samples/guides/lab-6-10.png)

5. 반드시 「다시 시작」으로 재부팅합니다 — 전원 끄기로는 적용이 안 되는 경우가 있습니다

`Hyper-V` 항목이 보여도 체크하지 않으셔도 됩니다.

### Step 4. 폴더가 붙었는지 확인하기

프로젝트 화면에서 **컨텍스트** 칸을 봅니다. 방금 붙인 `claude_lab` 이 보이면 성공입니다.

![sales_report 프로젝트 화면 오른쪽 컨텍스트 칸에 claude_lab 폴더가 들어 있는 모습](/samples/guides/lab-6-12.png)

한 줄 시켜서 정말 보는지 확인합니다. 입력창에 아래를 그대로 넣으세요.

```
지금 연결된 폴더 안에 어떤 파일과 폴더가 있는지 목록으로 보여주세요.
지어내지 말고 실제로 있는 것만 알려주세요.
```

![입력창에 두 줄짜리 프롬프트를 붙여넣고 보내기 화살표가 켜진 모습](/samples/guides/lab-6-13.png)

![폴더 접근을 허용할지 묻는 창의 Allow 단추와 다시 묻지 않기 체크](/samples/guides/lab-6-14.png)

`01_docs` 안의 파일 이름들이 나오면 제대로 붙은 것입니다.

![claude_lab 폴더 구성을 나무 모양으로 답해준 화면 — 01_docs 안의 csv 파일 이름들이 보인다](/samples/guides/lab-6-15.png)

## 알아둘 이름 셋

![왼쪽 목록의 새로 생성·프로젝트·아티팩트·예정됨·발송·사용자 지정 차례](/samples/guides/lab-6-11.png)

- **프로젝트(project)** — 폴더에 이름표를 달아둔 것. 앞으로 "프로젝트를 여세요"라고 하면 오늘 만든 이걸 말합니다.
- **아티팩트(artifact)** — AI가 만들어낸 결과물이 따로 모이는 자리입니다. 대화는 흘러가고, 아티팩트는 남습니다.
- **커넥터(connector)** — 앱 바깥 서비스에 손이 닿게 해주는 연결 통로. 왼쪽 목록 맨 아래 **사용자 지정** 안에 있습니다.
- **프롬프트(prompt)** — AI에게 시키기 위해 쓰는 글. 앞으로 계속 나올 말입니다.

## 이렇게 되면 성공이에요

- 바탕화면에 `claude_lab` 1개, 그 안에 하위 폴더 3개가 있다
- `01_docs` 안에 파일 2개 + 폴더 1개(안에 열두 개)가 들어 있다
- 프로젝트가 만들어지고 **컨텍스트** 칸에 `claude_lab` 이 보인다
- 폴더 목록을 물었을 때 내가 넣어둔 파일 이름이 답에 나온다

## 직접 해보기 (도전)

만들 때 목표 한 줄은 적었습니다. 이번엔 **지켜야 할 것**을 더 적어둡니다.
프로젝트 화면의 **지침** 칸에 아래를 넣어봅니다.

```
- 결과 파일은 02_output 폴더에 만들어 주세요
- 01_docs 안의 원본 파일은 절대 고치지 마세요
- 숫자를 다룰 때는 지어내지 말고 실제 파일 내용만 쓰세요
```

![프로젝트 화면 지침 칸 오른쪽 위의 연필 모양 편집 단추](/samples/guides/lab-6-16.png)

![지침 편집 창에 세 줄을 적고 저장을 누르는 모습](/samples/guides/lab-6-17.png)

목표 칸이 "무엇을 하는 자리인가"라면, 지침 칸은 "어떻게 해야 하는가"입니다.
둘 다 적어두면 매번 말하지 않아도 지켜집니다.
