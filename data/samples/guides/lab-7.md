## 이번 실습에서 만드는 것

- `02_output` 폴더에 정리된 엑셀 파일 `sales-2026-clean.xlsx` 1개

## 어떤 자료인가

`01_docs/sales-2026-messy.csv` 는 점포 열두 곳이 각자 보내온 걸 한 파일에 이어 붙인 자료입니다.
440줄이고, 점포마다 엑셀에 적는 버릇이 달라 이렇게 섞여 있습니다.

- 어디는 `11320000`, 어디는 `11,320,000`, 어디는 뒤에 `원`까지 붙여 보냈습니다
- 날짜도 `2026-05` · `2026.05` · `26/05` 가 섞여 있습니다
- 어떤 점포는 `전주점`이라고 보냈는데, 어떤 곳은 그냥 `전주`라고 보냈습니다
- 두 번 보낸 점포도 있고, 담당자가 최근에 바뀐 곳은 그 칸이 비어 있습니다

여러 곳에서 각자 만든 걸 모으면 원래 이렇게 됩니다. 그걸 다루는 게 이번 실습입니다.

**바로 "정리해줘"라고 하지 않습니다.** 먼저 무엇이 잘못됐는지 묻고, 그다음에 어떻게 고칠지 정해서 시킵니다.

## 이렇게 해보세요

### Step 1. 문제부터 물어보기

`sales_report` 프로젝트를 엽니다. **파일을 따로 올리지 않습니다** — 폴더가 이미 붙어 있으니 이름만 말하면 됩니다.

```
01_docs 폴더의 sales-2026-messy.csv 를 열어서 어떤 문제가 있는지 알려주세요.

- 전체가 몇 줄인지 먼저 알려주세요
- 빠진 값, 완전히 똑같이 반복된 줄, 형식이 서로 다른 칸을 찾아 주세요
- 같은 것을 가리키는데 표기가 다른 값이 있는지도 봐주세요
- 문제 종류별로 몇 건인지 표로 정리해 주세요

지어내지 말고 실제 파일 내용만 보고 답해 주세요.
```

![전체 441줄·컬럼 6개를 짚어주고 문제 종류별 건수를 표로 답해준 화면](/samples/guides/lab-7-1.png)

"지어내지 말고 실제 파일 내용만 보고"를 붙이는 이유는, 파일을 제대로 못 읽었을 때도
그럴듯한 답을 만들어내는 경우가 있기 때문입니다. 이 한 줄을 붙이면 그런 일이 줄어듭니다.

### Step 2. 진단 결과에서 무엇을 볼까

받은 표를 그냥 넘기지 말고 세 가지만 봅니다.

- **전체 줄 수** — 이 숫자가 뒤에서 검산의 기준이 됩니다
- **완전히 반복된 줄이 몇 건인지** — 정리 후 줄 수를 미리 계산할 수 있습니다
- **표기가 다른 값이 있는지** — 오늘의 진짜 함정입니다

점포 이름이 여러 가지로 적혀 있으면 점포별 합계를 낼 때 한 점포가 두 곳으로 잡힙니다.
표를 눈으로 볼 땐 멀쩡해 보여서 더 위험합니다.

### Step 3. 고칠 기준을 정하기

그냥 "정리해줘"라고 하면 내가 원하지 않는 방식으로 고칠 수 있습니다.
담당자가 비어 있는 줄을 통째로 지워버릴 수도 있고, 지워지면 못 되돌립니다.

| 문제 | 어떻게 할까 |
|---|---|
| 숫자에 쉼표가 있고, 뒤에 "원"이 붙은 것도 있다 | 숫자만 남긴다 |
| 똑같은 줄이 두 번 들어가 있다 | 하나만 남긴다 |
| 담당자 칸이 비어 있다 | 지우지 않고 표시해 둔다 |
| 날짜가 제각각이다 | 한 가지 형태로 통일한다 |
| 같은 점포인데 이름이 다르게 적혀 있다 | 가장 많이 쓰인 이름으로 통일한다 |

세 번째를 눈여겨보세요. 비어 있다는 사실 자체가 정보입니다 — 누가 담당인지 확인해야 한다는 뜻이니까요.

### Step 4. 기준을 넣어 정리시키고 파일로 받기

```
01_docs/sales-2026-messy.csv 를 아래 기준으로 정리해 주세요.

- 매출액은 쉼표와 "원"을 빼고 숫자만 남겨 주세요
- 똑같이 반복된 줄은 하나만 남겨 주세요
- 담당자가 비어 있는 줄은 지우지 말고 "확인필요" 라고 채워 주세요
- 연월은 2026-01 형태로 통일해 주세요
- 같은 점포인데 이름이 다르게 적힌 것은 가장 많이 쓰인 이름으로 통일해 주세요

정리한 결과를 02_output 폴더에 sales-2026-clean.xlsx 로 저장해 주세요.
원본 파일은 고치지 마세요.

저장한 뒤에 아래를 표로 알려주세요.
- 정리 전 줄 수와 정리 후 줄 수
- 정리 후 점포가 모두 몇 곳인지
- 무엇을 몇 건 고쳤는지
```

![저장을 마쳤다는 답과 정리 전 440줄·정리 후 432줄·차이 −8 을 정리한 표](/samples/guides/lab-7-2.png)

화면에 표를 보여주는 것과, 내 컴퓨터에 파일로 만드는 것은 다른 일입니다.
마지막 세 줄은 다음 단계에서 맞춰볼 숫자를 미리 받아두는 것입니다.

**파일이 안 생겼을 때**

- 바탕화면 `claude_lab/02_output` 폴더를 열어 직접 확인합니다
- 없으면 "파일이 실제로 만들어졌는지 확인하고, 안 됐으면 다시 만들어 주세요" 라고 시킵니다
- 필요한 도구를 설치해도 되냐고 물으면 허용을 누릅니다

### Step 5. 받은 숫자가 맞는지 확인하기

받았다고 끝이 아닙니다. 440줄을 손으로 셀 수는 없으니 엑셀이 세어주는 것을 한 번 봅니다.

1. `02_output/sales-2026-clean.xlsx` 를 엑셀로 엽니다
2. `Ctrl` + `End` 를 누릅니다. 자료의 맨 끝 칸으로 한 번에 이동합니다
3. 화면 왼쪽 행 번호를 봅니다. 머리글이 한 줄이니 행 번호에서 1을 뺀 것이 줄 수입니다

![Ctrl+End 로 이동한 엑셀 마지막 칸 — 왼쪽 행 번호가 433 이고 담당자 칸에 확인필요가 보인다](/samples/guides/lab-7-3.png)

이 숫자를 앞에서 받은 답과 맞춰봅니다.

| 맞춰볼 것 | 맞으면 |
|---|---|
| 엑셀이 보여준 줄 수 = AI가 말한 정리 후 줄 수 | 파일을 끝까지 읽고 제대로 저장한 것 |
| 정리 전 줄 수 − 중복 건수 = 정리 후 줄 수 | 지운 만큼만 지운 것 |
| 점포가 열두 곳 | 이름이 제대로 통일된 것 |

- 점포가 열세 곳 이상이면 같은 점포가 다른 이름으로 세어진 것입니다. "점포 이름을 다시 통일하고 저장해 주세요" 라고 한 번 더 시키세요.
- 줄 수가 안 맞으면 대개 파일을 끝까지 안 읽은 것입니다. "파일 전체를 처음부터 끝까지 다시 확인해 주세요" 라고 시키면 됩니다.

### Step 6. 이름을 하나 알고 가기

**환각(hallucination)** — AI가 사실이 아닌 내용을 사실인 것처럼 그럴듯하게 만들어 답하는 현상.

문장이 자연스러워서 겉으로는 구분이 안 됩니다. 그래서 숫자가 나오면 하나라도 맞춰보는 습관이 필요합니다.

## 이렇게 되면 성공이에요

- 고친 내역 표를 받았다
- 줄 수 · 중복 건수 · 점포 수 세 가지를 대조해서 맞았다
